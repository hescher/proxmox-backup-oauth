# Privacy Policy

This is a private backup application using rclone
and the Google Drive API.

The application accesses Google Drive only to
upload, list, download and manage backup files.

Backup data is encrypted locally before upload.

OAuth credentials are stored locally on the
administrator's server.

No Google user data is sold or shared with
third parties by the application.

Backup files are stored in the authorized
Google Drive account.

Access can be revoked at any time through
Google Account security settings.

This application is intended exclusively
for personal use.
